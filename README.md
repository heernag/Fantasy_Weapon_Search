# AI 기반 판타지 무기 멀티모달 검색 시스템

이미지와 자연어 조건을 결합해 2D 판타지 무기 에셋을 검색하는 5인 팀 프로젝트입니다.

## 핵심 기능

- 자연어 기반 에셋 검색
- 이미지 유사 에셋 검색
- 이미지+자연어 조건 변경 검색
- 카테고리·색상·속성·스타일·형태 필터
- Recall@K, MRR, 조건 만족률 평가

## 데이터 목표

- 최소 기준: 라이선스와 출처가 확인된 정제 이미지 1,000장
- 확장 목표: 3,000장 이상
- 우선 라이선스: CC0
- 보조 라이선스: 제작자 표시가 가능한 CC BY
- 표현 형식: 투명 또는 단색 배경의 2D 판타지 무기 아이콘·일러스트

## 저장소 구조

```text
data/
├─ metadata/              데이터 스키마·라벨·예시
├─ evaluation/            검색 요청·평가 질의 예시
├─ raw/                   원본 파일(기본적으로 Git 제외)
├─ interim/               정제 중간 파일(Git 제외)
└─ processed/             검색용 최종 이미지(Git 제외)
docs/
├─ data_collection_plan.md
└─ source_inventory.csv
```

## 데이터 담당 시작 순서

1. `docs/source_inventory.csv`에 후보 에셋 팩과 라이선스를 기록합니다.
2. `data/metadata/tag_dictionary.json`의 고정 라벨을 팀과 확정합니다.
3. 표본 200~300장을 수집해 정제·태깅 시간을 측정합니다.
4. `data/metadata/assets.example.json` 형식으로 50~100장을 시험 라벨링합니다.
5. 3일차에 최소 1,000장 확보 가능 여부를 결정합니다.

## 공통 규격

- 단일 값은 문자열 또는 `null`로 저장합니다.
- 여러 값은 배열로 저장합니다.
- 확인되지 않은 정보는 추측하지 않고 `null`로 저장합니다.
- 이미지 자체는 JSON에 넣지 않고 상대 경로만 저장합니다.
- 출처 URL과 라이선스는 반드시 기록합니다.
- 동일 에셋 팩과 동일 원본의 변형은 같은 split에 배정합니다.

자세한 규칙은 [데이터 수집 계획](docs/data_collection_plan.md)을 참고하세요.
