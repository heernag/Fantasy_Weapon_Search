| 데이터셋 | train | validation | test | 합계 |
| --- | ---: | ---: | ---: | ---: |

| 렌더 아이콘 | 121 | 15 | 14 | 150 |

- 분할 비율 목표: 80% / 10% / 10%
- 고정 시드: 픽셀아트·일러스트 `20260807`, 렌더 아이콘 `20260812`
- 분할 단위: 같은 시각 변형으로 판정된 이미지는 동일 split에 함께 배치
