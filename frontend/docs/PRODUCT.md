# Product

## Register

product

## Platform

web

## Users

게임 제작자와 아트 디렉터가 제작 중인 게임의 분위기와 요구 조건에 맞는 2D 판타지 무기 에셋을 빠르게 찾는다. 사용자는 보통 참고 이미지와 짧은 자연어 조건을 함께 가지고 있으며, 검색 결과를 비교하고 출처와 라이선스를 확인해야 한다.

## Product Purpose

Arcane Arsenal은 이미지와 자연어를 결합해 2D 판타지 무기를 탐색하는 발표용 검색 도구다. 시각적 유사성뿐 아니라 색상, 속성, 무기 형태, 스타일 조건을 명확히 확인할 수 있어야 한다.

## Positioning

참고 이미지의 형태와 자연어 조건을 한 번의 검색 흐름에서 설명 가능한 결과로 연결한다.

## Brand Personality

정밀하고, 차분하며, 탐색에 집중하는 도구다. 판타지 소재를 사용하되 장식보다 정보의 신뢰성과 조작의 명확성을 우선한다.

## Anti-references

과도한 중세 장식, 금색 테두리, 유리 질감 카드, 장식용 그라데이션, 불필요하게 복잡한 대시보드를 피한다.

## Design Principles

- 검색 조건과 결과 근거를 같은 화면에서 이해할 수 있게 한다.
- 결과 이미지는 시각적으로 비교하기 쉽고 메타데이터는 빠르게 훑을 수 있게 한다.
- 목데이터 상태와 실제 검색 기능의 경계를 화면에서 정직하게 알린다.
- 키보드와 작은 화면에서도 검색 흐름을 유지한다.

## Accessibility & Inclusion

한국어 UI를 기본으로 하며, 명확한 레이블과 키보드 포커스 상태를 제공한다. 색상만으로 상태를 구분하지 않고, 애니메이션은 줄이기 설정을 존중한다.
